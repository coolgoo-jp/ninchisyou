認知症は誰にでも起こりうる脳の病気です。原因を理解し、毎日の生活を少し整えることで、自分らしく過ごせる時間を延ばすことができます。

認知症とは？

認知症とは、いろいろな原因で脳の細胞が壊れたり、働きが悪くなったりすることで、日常生活に支障が出ている状態のことを指します。

単なる物忘れとの違い： 体験したことの一部（朝食の内容）を忘れるのが「物忘れ」、体験したこと自体（食べたこと）を忘れるのが「認知症」のサインです。

認知症を引き起こす「4つの原因」

Type 01

アルツハイマー型

認知症全体の約7割を占めます。脳に「アミロイドβ」という特殊なたんぱく質が溜まり、神経細胞が死滅して脳が萎縮（縮むこと）していくのが原因です。

  • ・新しいことが覚えられない
  • ・時間や場所がわからなくなる
Type 02

血管性認知症

脳梗塞や脳出血などで、脳の血管が詰まったり破れたりすることで起こります。生活習慣病（高血圧や糖尿病）との関わりが非常に深いです。

Type 03

レビー小体型

「レビー小体」というたんぱく質の塊が脳にできるのが原因です。実際にはないものが見える「幻視」や、手足の震えが特徴です。

Type 04

前頭側頭型

脳の前（前頭葉）や横（側頭葉）が萎縮します。感情の抑制が効かなくなったり、言葉がうまく出なくなったりします。

その他の原因

慢性硬膜下血腫や正常圧水頭症など、治療によって「治る認知症」もあります。まずは専門医による診断が不可欠です。

日常生活でできる対策

「脳活」は、早ければ早いほど効果的です。

1

食事：脳を守る栄養を

野菜、果物、魚（オメガ3脂肪酸）を積極的に摂る「地中海式」に近い食事が理想です。塩分を控え、高血圧を防ぎましょう。

2

運動：1日30分の散歩

歩くことで脳の血流が良くなります。しりとりをしながら歩くなど「2つのことを同時に行う」とさらに効果的です。

3

交流：会話は最高の刺激

人と会って話すことは、脳のあらゆる機能を使います。趣味の集まりや地域のイベントに顔を出してみましょう。
